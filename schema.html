Data schema

Tables behind the dashboard. Load db/schema.sql and db/seed.sql into SQLite to create the database.

How to create the database

sqlite3 db/support.db < db/schema.sql
sqlite3 db/support.db < db/seed.sql
sqlite3 db/support.db "SELECT metric_date, csat_pct, mttr_hours, deflection_pct FROM daily_metrics;"

Full column dictionary: docs/data-schema.md. PRD and BRD sit next to it.
